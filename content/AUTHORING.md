# دليل إعداد محتوى حصة جديدة في «تسمياتي»

المحتوى التعليمي منفصل عن الشيفرة. كل حصة ملف JSON في `content/lessons/`. لا تحتاجين إلى تعديل أي شيفرة لإضافة حصة.

## الخطوات

1. افتحي ملف الحصة (مثل `lesson-02.json`). ستجدين فيه بيانات الحصة والمهارات وفق خطة التوزيع، و`activities` فارغة.
2. انسخي بنية أي نشاط من `lesson-01.json` وعدّلي محتواه. يجب أن تغطي الأنشطة **الخطوات السبع كلها وبترتيبها** (الحقل `stage` من 1 إلى 7). يجوز أن تتضمن الخطوة أكثر من نشاط.
3. أضيفي `productFields` و`rubric` للحصة (المنتج المستقل ومعايير تقويمه).
4. غيّري `"status": "draft"` إلى `"status": "authored"`.
5. شغّلي `npm run validate`. يتحقق السكربت من:
   - وجود الخطوات السبع بالترتيب.
   - أن مهارات كل نشاط من مهارات الحصة المعتمدة (1–18 فقط).
   - أن مؤشرات الدافعية من المؤشرات الستة والعشرين المعتمدة.
   - أن الخطوة السادسة تعطّل المساعد التوليدي (`"independent": true` و`"mode": "disabled"`).
   - أن الخطوة السابعة تحدد المنتج المستقل الذي تقوّمه (`"evaluation": {"sourceActivity": "..."}`).
   - أن كل متطلب في `requirements.fields` حقلٌ موجود في ورقة العمل.
6. أعيدي تشغيل الخادم، ثم راجعي الحصة من لوحة المعلمة ← المحتوى ← «معاينة كما تراها الطالبة»، واعتمديها، ثم أتيحيها.

## عناصر النشاط

| الحقل | الوظيفة |
|---|---|
| `stage` | رقم خطوة الاستراتيجية (1–7) |
| `goal`، `expectedOutput` | هدف النشاط ومخرجه |
| `skills` | أرقام المهارات المستهدفة (من قائمة المهارات المعتمدة) |
| `motivation` | معرفات مؤشرات الدافعية: C1–C9، A1–A8، R1–R9 |
| `teacherProcedures`، `studentProcedures` | الإجراءات (إجراءات المعلمة لا تظهر للطالبة افتراضيًا) |
| `materials` | المادة التعليمية: `scenario`، `task`، `note`، `examples`، `criteria` (مع `revealAfter` لكشفها بعد محاولة الطالبة)، `thinkAloud` (تفكير يُكشف خطوة خطوة)، `modelCard` |
| `assistant` | اسم المساعد، ووظيفته `mode` (dialogue / modeling / disabled / evaluation)، ومستوى المساندة، والرسالة الافتتاحية، والأسئلة بالتتابع مع تلميحاتها، والختام، والضوابط |
| `worksheet.sections` | أقسام ورقة العمل وحقولها: `text`، `textarea`، `chips`، `choice`، `classify`، `table`، `ordering`، `list`، و`outline` (مخطط أفكار وتفصيلات). وللنصوص الطويلة: `minWords` و`minParagraphs` و`longText`؛ وللنصوص التدريبية: `defaultValue` و`mustChange`؛ ولاسترجاع منتج سابق: `prefill`. ولكل قسم تلميحات متدرجة `hints` وسياسة `hintPolicy` (always / after_attempt) |
| `answerKey` | للترتيب والاختيار فقط؛ لا يُرسل إلى الطالبة، ويُستخدم للفحص الموضوعي |
| `peer` | تفعيل ركن الزميلات والحقول التي تُشارك (بعد موافقة المعلمة) |
| `showProducts` | منتجات حصص سابقة تُعرض للطالبة ويطّلع عليها المساعد |
| `requirements` | الحد الأدنى للانتقال إلى النشاط التالي |

يمكن للمعلمة بعد ذلك تعديل تعليمات المساعد ومعايير التقويم من لوحة التحكم دون المساس بالملف.
