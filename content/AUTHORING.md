# إعداد الحصص

الحصص التسع مبنية من كتاب الطالبة (الوحدة التدريبية الرابعة) بمراحل استراتيجية «تسمياتي» السبع.

| الملف | ما فيه |
|---|---|
| `source/book.mjs` | نصوص الكتاب وأنشطته منقولة حرفيًا (التعليمات بصيغة المؤنث): أقسام فيها نصوص وإطارات «اقرئي» وجداول وحقول |
| `source/program.mjs` | توزيع الكتاب على الحصص: لكل حصة الدرس والصفحات والأهداف والمعايير، ولكل مرحلة مهمة من أقسام الكتاب (`S(...)`) أو إضافة داعمة بسيطة (`SUP(...)`)، والنشاط المنزلي |
| `source/helpers.mjs` | أدوات الحقول (اختيار، جدول، ترتيب، مطابقة...) |

## خطوات التعديل

1. عدّلي نص الكتاب في `book.mjs`، أو توزيعه في `program.mjs`.
2. `npm run lessons` ثم `npm run check-book` ثم `npm run validate`.

قواعد يتحقق منها البناء والفحص:
- لكل حصة الخطوات السبع بترتيبها، ومهمة إنتاج مستقل (المساعد معطل فيها)، ومهمة تقويم وتحسين تحدد المنتج المستقل.
- المهارات الثماني عشرة بصياغتها المعتمدة، ومؤشرات الدافعية الستة والعشرون.
- كل عنصر من صفحات الوحدة (147–187) موجود في الحصة المحددة له.
